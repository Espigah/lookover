Pergunte a um terminal
o que o outro está fazendo.

Cada sessão do Claude Code roda isolada. O lookover deixa você referenciar outro terminal, por nome ou por descrição, e injeta o contexto dele automaticamente. Tudo local, via hooks.

Na prática

Você não roda comando nenhum. Só menciona o outro terminal num prompt normal.

você, no terminal de review
com base no terminal onde trato o oncall, por que o alerta xpto não foi tratado?
lookover injeta automático
<<<LOOKOVER: contexto de outra sessão>>>
## terminal oncall-terminal
skill atual: oncall-patrolman
- pediu: investiga o alerta xpto de chargeback
- fato: alerta veio sem group_id
<<<FIM>>>
claude
No terminal do oncall o alerta xpto parou porque chegou sem group_id…

Como funciona

Três peças, todas locais. Nenhum daemon, nenhum servidor.

1

Captura

Um hook leve (100% Go, zero token) grava um resumo enxuto de cada sessão: tópicos, skill em uso, fatos. Sem guardar conteúdo verbatim.

2

Resolve

Ao mencionar outro terminal, varre as sessões vivas e ranqueia por nome, tópicos, repo e skill. Acha a certa, ou pede pra desambiguar.

3

Injeta

O contexto da sessão alvo entra no seu prompt como dado (envelope anti-injection). O Claude responde já sabendo o que a outra fez.

Dois níveis de contexto

Barato por padrão, profundo quando você precisa.

Resumo

Tópicos e o que foi pedido, pra identificação rápida. É o que entra na maioria das vezes, custo mínimo de token.

Conteúdo completo

Peça “o texto completo”, “na íntegra”, “o que foi escrito” e o lookover lê o transcript real da outra sessão e injeta o conteúdo verbatim.

Instalar

Requer Go 1.21+ e o Claude Code. O init mostra o diff do settings.json e só aplica após você confirmar.

# clona e compila
git clone https://github.com/Espigah/lookover.git
cd lookover
go build -o ~/.local/bin/lookover ./cmd/lookover

# registra os hooks (interativo, com dry-run + backup)
lookover init

Reverter a qualquer momento com lookover uninstall. Kill switch instantâneo: touch ~/.claude/lookover/disabled.

Comandos

Além da referência automática nos prompts, há uma CLI pra inspecionar.

lookover list                   # sessões vivas + tópicos/skill
lookover show <nome|id>          # o digest de uma sessão
lookover doctor                 # saúde: sessões, digests, versão
lookover status                 # adoção: vivas x cobertas

Pensado pra não atrapalhar

Roda em todo prompt; foi desenhado pra ser invisível quando não é preciso.

  • Custo zero no uso normal: sem referência a outro terminal, não injeta nada.
  • Nunca quebra o Claude: recover de panic, watchdog anti-hang, sempre sai limpo.
  • Anti prompt-injection: nunca guarda output verbatim no resumo; tudo envelopado e sanitizado.
  • Sem servidor: um arquivo por sessão, escrita atômica, resolução por varredura local.
  • Local de verdade: nada sai pra rede além da compactação opcional por LLM (off por padrão).
